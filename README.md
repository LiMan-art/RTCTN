# RTCTN

Программа для Windows, показывает уведомление в заданное время. Работает в фоновом режиме без окон.

## Когда срабатывает

- Будние дни (пн–пт): в 00:00.
- Выходные (сб, вс): в 00:00 и в 12:00.
- Праздничные дни и переносы выходных (по производственному календарю РФ): в 00:00 и в 12:00.

Статус дня определяется через производственный календарь. Рабочие субботы (переносы) считаются рабочими днями — полдень в них не срабатывает.

## Требования

- **Интернет** для корректной работы. При первом запуске и при истечении кеша (по умолчанию 60 дней) программа скачивает актуальный производственный календарь с `xmlcalendar.ru`. Без сети данные не загрузятся, и скрипт завершится с ошибкой.
- Загруженный календарь кешируется в папке `.cache/` рядом с программой. После первого успешного запуска программа работает без сети до истечения срока кеша.

## Закрытие

Окна у программы нет. Чтобы остановить, откройте «Диспетчер задач» (`Ctrl+Shift+Esc`), найдите процесс `RTCTN.exe` и завершите его.

## Автозапуск

1. Нажмите `Win+R`.
2. Введите `shell:startup`.
3. Поместите в открывшуюся папку ярлык на `RTCTN.exe`.

## Настройка

Настройка выполняется в исходном коде `script.py`, после чего файл пересобирается:

messagebox.showinfo('ЭЭЭЭЭЭЭЭЙ', 'ПРОВЕРЬ ОПОВЕЩЕНИЕ') # текст уведомления(заголовок, текст)

if hour == 0:                       # полночь, любой день
    ...

elif is_day_off and hour == 12:     # выходной/праздник, полдень
    ...

## Удаление

Программа не устанавливается в систему и не создаёт служб, поэтому удаление сводится к удалению файлов.

1. **Остановите процесс**, если он запущен: «Диспетчер задач» (`Ctrl+Shift+Esc`) → найдите `RTCTN.exe` → «Снять задачу».
2. **Удалите автозапуск**, если настраивали: `Win+R` → `shell:startup` → удалите ярлык `RTCTN`.
3. **Удалите файлы программы**: сам `RTCTN.exe` и папку `.cache/` рядом с ним (в ней хранится загруженный календарь).

Всё. Записей в реестре и других следов программа не оставляет.
